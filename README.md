# Prompter

A browser-based digital teleprompter served from a single static HTML file.

## Run locally

Open `index.html` in a modern web browser. No installation or build step is required.

The app can also be served by any static web server. Google Fonts are loaded over the internet.

## Project files

- `index.html` — application markup, styles, and JavaScript.
- `teleprompter-requirements.md` — original project requirements.
